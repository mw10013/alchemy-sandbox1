# Host adapter: T3 Code

How the skill's neutral actions map to T3 Code. Tool names may carry a prefix (`mcp__t3-code__t3_thread_launch`); the semantics are the same. If the T3 tools do not show in the tool list, make one direct attempt by name before concluding they are absent.

| Action                           | T3 Code                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Review gate                      | `PLANNOTATOR_BROWSER=Safari plannotator annotate docs/<file>.md --gate --json`, run in the background with a long timeout (it blocks until the user submits). Read its stdout JSON when it exits: `"decision"` and a markdown `"feedback"` listing annotations by line, each "Looks good" or quoted text.                                                                                        |
| Launch the implementation thread | `t3_thread_launch` with `modelSelection {instanceId: "claudeAgent", model: "claude-opus-5-5"}`, the brief in `message` (not `prompt`), a `title`, and a workspace: `{type: "root"}` for `main`; `{type: "existing_worktree", worktreePath: "/Users/mw/.t3/worktrees/baton/wt-01", branch: "wt-01"}` for the worktree (run `git merge --ff-only main` in it first). Keep the returned `threadId`. |
| Launch the next orchestrator     | `t3_thread_launch` the same way, workspace `{type: "root"}`, the handoff brief in `message`. It is a top-level thread the user can open.                                                                                                                                                                                                                                                         |
| Wait for a thread                | `t3_thread_wait`, bounded (up to 30 minutes per call), for the terminal state; `t3_thread_read` to read what it said.                                                                                                                                                                                                                                                                            |
| Send a follow-up                 | `t3_thread_send` to the thread id, mode `auto`. A launched thread cannot message you; everything it reports is in its replies and the plan's §7.                                                                                                                                                                                                                                                 |
| Watch §7                         | The `Monitor` tool with `until <grep for the marker in docs/<slice>-plan.md>; do sleep 90; done`. Markers: a `CHECKPOINT` line, text under "Human steps requested", an "Implementation review" entry. Re-arm when it expires.                                                                                                                                                                    |
| Lost launch                      | `t3_thread_launch` has no idempotency key. If a launch fails or its answer is lost, check `t3_thread_list` before launching again.                                                                                                                                                                                                                                                               |
| Link to a thread                 | `[title](t3-thread://v1/<threadId>)` in a message to the user.                                                                                                                                                                                                                                                                                                                                   |

T3 runs the Claude Code harness, so a launched thread with a Claude model loads this skill by name. A thread on another provider does not: tell it to read this folder's files directly.
