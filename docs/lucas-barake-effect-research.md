# Lucas Barake and Effect resources

The creator you were thinking of is very likely **Lucas Barake** (not “Lucas Brakas”). His [personal site](https://lucas-barake.github.io/) links his [YouTube channel](https://www.youtube.com/@lucas-barake) and [GitHub profile](https://github.com/lucas-barake), and Effect’s community updates credit him by name. I found no reliable source for an Effect creator named “Lucas Brakas.”

## TanStack Start + Effect

- **Video:** [TanStack Start with Effect-TS & Effect Atom](https://www.youtube.com/watch?v=xKQcedkMLPs), also listed in [Effect’s December 2025 community update](https://effect.website/blog/this-week-in-effect/96).
- **Code:** [lucas-barake/effect-tanstack-start](https://github.com/lucas-barake/effect-tanstack-start), with [source](https://github.com/lucas-barake/effect-tanstack-start/tree/main/src) and [package manifest](https://raw.githubusercontent.com/lucas-barake/effect-tanstack-start/main/package.json).
- It is a small sample app—not a published integration package. Its README is still the generic TanStack starter guide, the manifest marks the app `private`, and the visible dependencies include Effect 3.19.10 and TanStack Start 1.132.0. The visible commits are from December 2025, so check compatibility before reusing it.
- Don’t confuse it with the separate, unrelated [EthanShoeDev/effect-tanstack-start](https://github.com/EthanShoeDev/effect-tanstack-start) repository.

## Course and other learning material

- **Paid course:** [Practical Effect](https://buymeacoffee.com/lucasbarake/e/459986) is Barake’s independently sold video course. Its listing showed **$79** when checked and described Effect fundamentals, typed errors, services/layers, concurrency, Schema, testing, and a server project. The listing says it currently covers Effect 3 and a V4 update is pending; recheck price and status on the seller page. Effect’s [community newsletter](https://effect.website/blog/this-week-in-effect/87) also identifies it as Barake’s course; it is not an official Effect course.
- **Effect Atom course:** [Separate early-access listing](https://buymeacoffee.com/lucasbarake/e/551346). It gave an August 2026 target date, which has passed, but still labeled the course early access at research time; completion or launch is unconfirmed.
- **Free videos and code:** [YouTube channel](https://www.youtube.com/@lucas-barake); [Building an App with Effect repository](https://github.com/lucas-barake/building-an-app-with-effect); [Effect Schema V4 Crash Course](https://www.youtube.com/watch?v=0naAPm0-0Wg).
- **Free written tutorials:** [Effect RPC for Workers](https://lucas-barake.github.io/rpc-for-workers-in-typescript/), [Composable Policy System with Effect](https://lucas-barake.github.io/building-a-composable-policy-system/), and [Supporting Offline Mode in TanStack Query](https://lucas-barake.github.io/persisting-tantsack-query-data-locally/).
- **Official Effect resources (separate from Barake’s material):** [Effect documentation](https://effect.website/docs/) and [official workshops playlist](https://www.youtube.com/playlist?list=PLDf3uQLaK2B9vHzUNyvOSvoMv61LW7792).

## Sources and caveats

The strongest identity checks are Barake’s own [site](https://lucas-barake.github.io/) and his [GitHub profile](https://github.com/lucas-barake), cross-linked with Effect community posts, including [newsletter #61](https://effect.website/blog/this-week-in-effect/61/) and [#100](https://effect.website/blog/this-week-in-effect/100/). Course price, availability, version updates, repository activity, and dependency compatibility can change; the details above are observations from the cited pages, not guarantees of current status.
